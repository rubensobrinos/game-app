# Mobile review

Use this when changing a `react-native-app` repo.

- Check navigation, loading states, and permission flows.
- Keep platform-specific code isolated.
- Run lint, tests, and the configured build/export command.
- Avoid committing generated native artifacts unless the repo owns them.
