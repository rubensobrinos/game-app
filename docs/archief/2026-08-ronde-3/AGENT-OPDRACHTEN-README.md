# Agent-opdrachten

Elke ronde krijgt een eigen map: de briefings, de startprompts en het verslag.

| Ronde | Waarover | Stand |
| --- | --- | --- |
| [`ronde-2/`](../2026-08-mobiele-ux-ronde/) | 58 mobiele UX-punten, vier agents | afgerond, live |
| [`ronde-3/`](./) | hostacties, spelinstellingen, betrouwbaarheid | loopt |

**Werkwijze.** De producteigenaar levert de punten, de lead (regie) verdeelt ze
en schrijft per agent een briefing. Een agent werkt in een eigen worktree, doet
één ronde, stopt en levert op; de lead reviewt, merget en deployt. Agents
pushen nooit zelf.

Losse punten van een paar regels pakt de lead er zelf tussendoor bij — die
horen niet in een briefing.
