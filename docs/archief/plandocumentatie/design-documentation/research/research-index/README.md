# Research

Deze map bevat de twee ontvangen onderzoeksrapporten.

- `2026-08-03-COMPETITOR-AND-CURRENT-UI-AUDIT.md`: concurrentieprincipes en audit van de huidige UI.
- `2026-08-03-WORLD-PARTY-GAME-BENCHMARK.md`: benchmark en concrete visuele/schermrichting.

De bronrapporten mogen meningen, observaties en onderlinge spanningen bevatten. De samengevoegde besluiten staan onder `../design/`.

Belangrijkste verzoende spanning:

- rapport 1 bepleit kleur-/vormidentiteit per antwoord;
- rapport 2 bepleit neutrale antwoorden vóór reveal;
- ontwerpbesluit: letter + geometrische vorm en eventueel gedempt positieaccent, terwijl de button surface neutraal blijft en groen/rood pas na reveal verschijnt.
