# Implementatieplannen en fasecodes

Elke fasecode is uniek voor één domein. Gebruik altijd de volledige code in
prompts, reviews, commits en kruisverwijzingen; de oude, losse éénlettercodes zijn
niet meer geldig.

| Prefix | Domein | Plan | Voortgang | Promptmap |
| --- | --- | --- | --- | --- |
| `GR` | Game rules | [Plan](game-rules-plan/README.md) | [GR-PROGRESS](game-rules-plan/GR-PROGRESS.md) | [Prompts](game-rules-plan/prompts/) |
| `GF` | Game flow | [Plan](game-flow-plan/README.md) | [GF-PROGRESS](game-flow-plan/GF-PROGRESS.md) | [Prompts](game-flow-plan/prompts/README.md) |
| `DM` | Data model | [Plan](data-model-plan/README.md) | [DM-PROGRESS](data-model-plan/DM-PROGRESS.md) | [Prompts](data-model-plan/prompts/) |
| `PR` | Protocol | [Plan](protocol-plan/README.md) | [PR-PROGRESS](protocol-plan/PR-PROGRESS.md) | [Prompts](protocol-plan/prompts/README.md) |
| `PD` | Product | [Plan](product-plan/README.md) | [PD-PROGRESS](product-plan/PD-PROGRESS.md) | [Prompts](product-plan/prompts/) |
| `AR` | Architecture | [Plan](architecture-plan/README.md) | [AR-PROGRESS](architecture-plan/AR-PROGRESS.md) | [Prompts](architecture-plan/prompts/README.md) |
| `DT` | Deployment en testing | [Plan](deployment-and-testing-plan/README.md) | [DT-PROGRESS](deployment-and-testing-plan/DT-PROGRESS.md) | [Prompts](deployment-and-testing-plan/prompts/README.md) |

Subfasen behouden een kleine letter, bijvoorbeeld `GF2a` en `DT0b`. Een promptnaam
begint met dezelfde fasecode, bijvoorbeeld `GR1-scoring.md` of
`AR0-AR1-state-machine.md`. Reviews die specifieke fasen behandelen gebruiken die
codes eveneens, bijvoorbeeld `REVIEW-PD2-PD3.md`.
